# Triage labels

The engineering skills use these canonical roles. For this repository, the local `Status:` value is the same string.

| Canonical role | Local status | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer needs to evaluate the ticket. |
| `needs-info` | `needs-info` | More information is needed from the reporter. |
| `ready-for-agent` | `ready-for-agent` | The ticket is specified well enough for an agent to implement unattended. |
| `ready-for-human` | `ready-for-human` | The work needs a human implementer. |
| `wontfix` | `wontfix` | The ticket will not be worked on. |
